Sessions 5–6

ChatGPT Best Practices

Sep 27, 2026Day 3Hands-on

Why the setup around ChatGPT matters more than any single prompt — and how to prompt with structure and check what comes back.

Intended learning outcome

Navigate the ChatGPT interface and its key features, understand the range of managerial tasks it can support, and use well-structured prompts to generate, refine and analyse content — while critically evaluating outputs for accuracy, relevance and ethics.

Executive Summary

  • Best practice starts with environment setup — global instructions, projects, project instructions and a knowledge base — before any prompting
  • Structured prompting (for example CO-STAR) and a dedicated "prompt engineer" chat help turn vague intent into precise requests
  • A class discussion explored whether growing reliance on AI will erode human cognitive ability

ChatGPT Best Practices: Setting Up the Environment

  1. 1Global personalisation — under Personalization → Custom Instructions, state your professional profile, role, typical tasks, preferred writing style and what you do not want, so every reply fits your context without re-explaining
  2. 2Project organisation — group work by domain using Projects (available in the free version); no chat is left outside a project, and a loose chat can be moved into one later
  3. 3Project-level instructions — each project can carry its own instructions, separate from the global ones
  4. 4Knowledge base — attach PDFs and documents under Sources so ChatGPT references them across every chat in the project
  5. 5Prompting frameworks — CO-STAR (Context, Objective, Style, Tone, Audience, Response format), used as far as each task needs; and a dedicated "prompt engineer" chat that converts a vague intent into a detailed prompt to paste into the working chat
  6. 6Expect interface drift — menus change often and differ by plan, so locations may vary

These layers work as a hierarchy: put each instruction in the broadest layer where it stays true. Your role belongs in global instructions, a recurring analytical stance belongs in one project, and a long reference report belongs in Sources rather than pasted into a chat.

Prompting as an exchange: generate, refine, analyse

Generate with a structured first prompt. Refine with targeted follow-ups such as "shorten to 120 words" or "rewrite for a sceptical CFO". Analyse material you provide: in the live demo, ChatGPT read all ten group sites, normalised the framework names and counted frequency — Six Sigma appeared five times and SWOT four. The first prompt retrieved only some of the sites; a corrected prompt listing every URL explicitly fixed it.

Managerial applications

Drafting emails and briefs; summarising long reports into executive notes; comparing options and extracting themes; structuring ideas and preparing cases; and building simple websites and apps, as in this course.

Evaluating outputs critically

  • Accuracy and completeness — check the output against its source; the demo showed an answer can be fluent yet incomplete
  • Relevance — does it fit your context and audience?
  • Ethics and ownership — AI may assist, but conclusions must be your own

Discussion: AI and Cognitive Ability

Responding to a question on responsible AI use, the professor drew an analogy with the Industrial Revolution: mechanisation reduced everyday physical strength while a minority developed exceptional strength, and new industries such as fitness emerged. By the same logic, wider AI reliance may lower intellectual engagement for most people while a minority builds exceptional capability, creating a wider gap — and new industries. He framed this as a personal perception and invited debate.

Leadership Reflection

What this session means for manufacturing leaders:

ChatGPT adds the most value when the user builds the environment first and checks the output afterwards. For manufacturing leaders, that means giving the tool context about the business, structuring the request, and keeping human judgement on the final call — the same discipline expected of any technical system.

The cognitive-ability discussion adds a leadership question: if AI makes thinking easier for everyone, advantage will go to those who keep exercising judgement. Using AI to extend one's reasoning rather than replace it is a capability worth building deliberately in teams.
